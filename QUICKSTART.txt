Clash Verge 监控器 · Ubuntu 26.04 ARM64
图形安装分享版 · 1.3.4

安装和日常打开都可以使用鼠标，不需要输入终端命令。
适用于带有“应用中心 / App Center”的 Ubuntu 26.04 桌面版。
首次安装请保持联网，并准备好这台 Ubuntu 的系统账户密码。

一、安装：解压 → 双击 → 安装

1. 把整个分享压缩包复制到目标 Ubuntu 电脑，例如“下载”文件夹。
2. 右键压缩包，选择“解压到此处”（也可能显示“提取到此处”），打开解压后的文件夹。
3. 双击 clash-verge-watchdog_1.3.4_all.deb。
4. 在“应用中心 / App Center”打开的页面中点击“安装”，按系统提示输入账户密码。
5. 等待安装完成。系统会下载缺少的 Python、Tk、GI 等依赖，不需要另外手动安装 Python。

文件名中的 all 表示程序适用于多种 CPU 架构，包括 ARM64。
只需安装一次。以后打开应用图标，不需要反复打开安装包。

二、打开程序

安装完成后，点击 Ubuntu 程序坞的“显示应用”按钮，搜索“Clash Verge 监控器”，点击图标打开。
也可以按键盘上的 Super / Windows 键，直接搜索应用名称。
想以后打开更方便，可右键运行中的程序坞图标，选择“固定到程序坞”或“添加到收藏夹”。
安装完成不会擅自启动监控，也不会修改 Clash 的连接设置。

三、首次使用

1. 先安装并打开适用于 ARM64 的 Clash Verge Rev。这个分享包只包含监控器。
2. 监控器 →“连接设置 / 使用说明”→“一键配置连接”。
3. 返回“监控”页 → 选择当前使用的代理组。
4. 点击“检查重启入口”，确认入口可用后再点“开始监控”。

如果提示没有启用控制接口：
在 Clash 的设置里启用“外部控制器”，地址设为 127.0.0.1:9097，并设置密钥；
在监控器里填写 http://127.0.0.1:9097 和同一密钥，再“连接并加载”。已有其他本机端口可以沿用。
这些设置也在图形界面完成。每台电脑独立读取自己的配置，不要分享密钥或 settings.json。

正常每30秒测速；失败后5秒复测；连续5轮双地址都失败才请求重启。
“Clash 退出后自动启动”为独立开关，默认开启。
托盘可用时关闭窗口会继续监控；通过托盘菜单打开窗口或退出。灰色表示未监控，绿色正常，黄色等待或需要关注，红色表示双地址测速失败。

四、双击没有出现安装窗口

如果打开的是压缩包管理器，或出现“选择应用”窗口：
关闭该窗口 → 右键 .deb 文件 →“打开方式 / 使用其他应用打开”→ 选择“应用中心 / App Center”。
不要解压 .deb；只解压外层的分享 ZIP。

如果“打开方式”没有应用中心，先在 Ubuntu 应用列表中查找“应用中心 / App Center”。
精简安装、被移除应用中心的系统或其他桌面环境，不保证具备这条图形安装入口；
此时先记录系统版本和当前画面，请协助安装的人检查，不必猜测输入命令。

如果提示下载依赖失败，先确认网络正常，然后回到应用中心重试。
如果提示系统正在更新或包管理器忙，等待更新结束再安装。
没有可安装软件的管理员账户时，需要该电脑的管理员完成系统密码确认。

五、更新与分享

更新前先关闭旧监控器，再用应用中心打开新 .deb。不要同时运行两个版本。
如果应用中心只显示“已安装”而没有更新入口，请保留提示信息，交给协助安装的人处理。
更新安装包不会清空当前用户的监控设置、日志或重启记录。

把收到的原始 Share.zip 发给其他人即可，不要另外加入自己的设置、日志或 Clash 配置。
包内“开始使用.html”是离线可打开的大字版说明；“安装说明.txt”是本说明；SHA256SUMS 是校验文件。
安装包不需要手动开启“允许作为程序执行”，也不需要运行额外的安装脚本。
